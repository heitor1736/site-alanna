# Vitória Marinho — Direito & Humanidade

Portfólio pessoal e acadêmico em português, desenvolvido com React, TypeScript, Vinext e Vite. Identidade editorial em papel e vinho, tipografia Cormorant Garamond/DM Sans e fotografia do Itamaraty.

## Desenvolvimento

Requer Node.js >= 22.13.0. Instale com `npm install` e execute `npm run dev`. O endereço aparece no terminal. `npm run build` gera a versão de produção compatível com Sites/Cloudflare Workers.
